# 🛡️ Fraud Detection System

A Machine Learning-based Fraud Detection Web Application built using **Python, Scikit-Learn, Streamlit, and KNN Algorithm**. This application predicts whether a transaction is genuine or potentially fraudulent based on transaction details.

## 📊 Input Features

The model uses the following features:

- transaction_amount
- hour_of_day
- is_weekend
- num_items
- customer_age
- prev_transactions
- distance_from_home
- device_type
- network_quality
- is_first_transaction
- store_type
- velocity_score

---

## 🤖 Machine Learning Model

- Algorithm: K-Nearest Neighbors (KNN)
- Model File: `knn_neighbour.pkl`
- Framework: Scikit-Learn
